Pulsaderm, LLC is a US maker of home LED devices. openFDA's 510(k) index returns exactly three clearances to it, all filed with a 510(k) Summary rather than a Statement, which is the more informative of the two options: K163329 for the Wrinkle Mask 28 and Wrinkle Mask 72 (April 2017, product code OHS, light-based over-the-counter wrinkle reduction), K170111 for the Acne Mask 28 and Acne Mask 37 (May 2017, code OLP), and K182501 for a Hair Laser Headband (October 2018, code OAP).[^openfda]

Covered here: [[pulsaderm-wrinkle-mask-28]] and [[pulsaderm-acne-mask-28]]. The Hair Laser Headband has no page yet. Modality evidence is on [[home-led-light-therapy]].

No brand claims are quoted on this page because there are none to quote: pulsaderm.com returns HTTP 423 with the body text "This store is unavailable", checked twice on 2026-11-01.[^store]
