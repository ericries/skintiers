# Tooling pass (overnight 4/5)

**Date:** 2026-07-29 · **Constraint:** run from the main loop under an active account spend limit
(subagents unavailable). Scope was deliberately bounded to the highest value/risk guardrails that could be
completed cleanly with strict TDD and a fully green suite. Bigger items are proposed, not built.

## Shipped (each TDD, suite green, committed separately)

### 1. `sk style` voice deny-list — `check_voice()` (commit 5b0ec0d)
Catches the whole class of house-voice violations that previously relied on a critic or a manual grep:
- **site self-reference** by name (`SkinTiers` in the body);
- **defensive meta-commentary**: `This page grades`, `What follows is`, `not a/our verdict`,
  `a matching INCI is not proof`;
- **process/roadmap language**: `queued`, `a later phase`, `not yet on the site`, `coming soon`.
Patterns are specific to avoid false positives — notably `not a finding` is NOT flagged when followed by
`of harm` (the QC 2/5 false-positive). Wired into `check_style`, so `sk style` surfaces it. **6 tests**
(`tests/test_sk_voice.py`).
**It immediately found 2 live violations the critics missed:** `This page grades` on
`rosacea-erythematotelangiectatic` and `sunscreen-uv-filters` — both should be rephrased (small content fix,
not done in this tooling pass; noted for a content pass / see below).

### 2. `sk lint` per-type required sections — `check_required_sections()` (commit f8c1202)
Warns when a `product` lacks `## Summary` or a `condition` lacks `How to know you have this`, driven by a
`REQUIRED_SECTIONS` map (easy to extend, e.g. study pages later). Kept **separate** from `check_profile` so
the core lint contract is unperturbed; `cmd_lint` appends it. Advisory **WARNING** (exit 2), not a hard
failure — **8 pre-standard product pages** currently lack `## Summary`
(the-ordinary-multi-peptide-copper-peptides-serum, la-roche-posay-anthelios-melt-in-milk-spf-60,
tretinoin-0-025-cream, beauty-of-joseon-light-on-serum-centella-vita-c, la-roche-posay-toleriane,
anua-azelaic-acid-serum, anua-nano-retinol-0-3-niacin-renewing-serum, cos-de-baha-az20-azelaic-acid-20-serum).
**5 tests** (`tests/test_sk_required_sections.py`); one existing lint fixture updated to current standard
(added `## Summary`) — not a weakening.

## Proposed, not done (bigger — for a future pass, or when the spend limit lifts)

These come straight from the five-whys (2026-07-29-five-whys.md), ordered by value/risk:

1. **Make `sk style` block publish** (five-whys pattern 2). Have `sk publish SLUG` run `sk style` and refuse
   on any finding, with a `--force` escape hatch consistent with the review-verdict gate; promote dashes/
   AI-ese from WARN to ERROR. Also give `sk audit` a "published-but-fails-style" category. Medium size; the
   risk is the 16 existing dash-carrying pages would need cleanup first (already escalated), so sequence:
   clean the 16, then flip the gate.
2. **Unattributed-imperative check** (five-whys pattern 1, the hard part). Detecting "apply twice daily"-style
   commands not attributed to a source needs NLP-ish heuristics (imperative-mood sentence not inside a quote
   or a "typically recommended" frame). Higher false-positive risk; prototype as WARN behind a flag.
3. **Unfootnoted-number lint in `## The Evidence`** (pattern 5). A paragraph in the Evidence section
   containing `%`, a CI, or `n=` must carry a `[^n]`. Small, high-value; promote the existing "uncited
   statistic" WARN to an Evidence-scoped ERROR.
4. **Image-integrity lint** (pattern 7). Every `images[].file` must resolve to an existing local file under
   `static/images/` and not be an `http(s)://` URL. Small; needs a couple of fixtures.
5. **Dead-xref / empty-stub-link report** (pattern 6). Fold the QC 2/5 detection into `sk audit`: list
   `[[slug]]` targets that don't resolve (they render as plain text today). Report only, not a hard failure;
   optionally `sk queue-add` each as discovered demand. Small.
6. **`sk verify` Apify fallback** (pattern 4). Route a 403'd domain through `apify/rag-web-browser` and
   maintain `data/anti-bot-domains.yaml` so claims resting solely on a blocked domain require a second
   fetchable corroborator. Largest; behind a flag; needs the Apify MCP available at run time.
7. **`build.py` tier-list helpers** (review-queue #1). An "At a glance" tier-nav built from `## Tier N:`
   headings + per-item cards, and a sunscreen filter-coverage visual (nm blocked per filter). This is a
   template/CSS feature, not a lint rule — better done in the visual-design pass with the design proposal in
   2026-07-29-ux-readability-audit.md, so the component is designed once and reused (also serves the
   See-Also→tier-list request).
