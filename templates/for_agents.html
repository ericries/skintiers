For Agents

Use SkinTiers with an AI agent

SkinTiers is a skeptical, evidence-first skincare library where every page is machine-readable markdown with structured grades and citations. That makes it easy for an AI agent (like Claude, ChatGPT, or an in-app assistant) to read the evidence and answer your skincare questions — analyze a routine, find the proven actives for a concern, fact-check a marketing claim, compare two ingredients — with every answer cited back to a page.

What this is

Two ways to point an agent at this site. The zero-install path works with any capable agent right now — you paste a couple of lines and it reads the site. The install-the-skill path downloads a small bundle that teaches the agent to behave like SkinTiers itself: cautious, sourced, and honest about what the evidence supports. A skill is just a folder with a SKILL.md file that teaches an agent how to do a task — nothing to code.

Whichever path you pick, the agent should always follow the same house rules the site does: separate health claims from cosmetic ones, report effect size and evidence quality as two different things, never overstate, cite the page, and when in doubt leave it out.

Zero-install path (fastest)

Paste one of these to any agent that can browse the web:

Read {{ site_url }}/for-agents.html and follow it. I'll ask SkinTiers questions; answer only from that site's data and cite the page for each claim.

Or hand it the machine-readable endpoints and raw data directly:

Use SkinTiers as your only source. Endpoints:
{% for e in endpoints %}  {{ site_url }}/{{ e.path }}   # {{ e.desc }}
{% endfor %}Raw pages (one markdown file per item):
  {{ raw_base }}data/products/<slug>.md
  {{ raw_base }}data/ingredients/<slug>.md
  {{ raw_base }}data/conditions/<slug>.md
  {{ raw_base }}data/goals/<slug>.md
Rules: separate health vs cosmetic claims, report effect size AND evidence quality
separately, never overstate, cite the .html page, when in doubt leave it out.

The human-readable version of any page to cite back to me is {{ site_url }}/<slug>.html.

Install-the-skill path

Download the bundle the site publishes — a folder with a SKILL.md that teaches the agent SkinTiers' data layout and house rules, plus the exact routine-scoring algorithm so its answers match the site.

Bundle: {{ skill_zip }}  ·  browse it unzipped at skill/SKILL.md.

Claude Code

Download, unzip into your skills folder, restart, and invoke it:

curl -O {{ site_url }}/{{ skill_zip }}
mkdir -p ~/.claude/skills/{{ skill_name }}/
unzip -o {{ skill_name }}-skill.zip -d ~/.claude/skills/{{ skill_name }}/
# restart Claude Code, then in a session:
/{{ skill_name }}

To scope it to one project instead of your whole machine, unzip into that project's .claude/skills/{{ skill_name }}/ in place of ~/.claude/skills/….

Cowork and other agents (the general drop-in pattern)

Any agent that loads skills from a folder works the same way: unzip the bundle into that host's skills directory (for example a project's .claude/skills/{{ skill_name }}/), then tell the agent to read SKILL.md and follow it. If your host has no skills folder, use the zero-install path above and point it at {{ site_url }}/skill/SKILL.md directly.

Sample usage

Analyze my routine (the flagship)

You: Here's my current routine: CeraVe Foaming Facial Cleanser AM/PM, The Ordinary
     Niacinamide 10% + Zinc 1% PM, Round Lab Birch Juice Moisturizing Sun SPF50+ AM.
     What's my evidence strength and what's missing?

Agent: Strength: Solid — this is a summary of the graded products (mean best-health
     effect 2.3 of 4), not a trial of the routine as a whole.
     · 3 products matched to SkinTiers pages.
     · Sunscreen: present, UVB + UVA coverage (avobenzone, octisalate, homosalate).
     · Actives covered: niacinamide.
     · Not present (informational): retinoid, vitamin C, exfoliant.
     Gap worth noting: no evening active for tone or aging — a retinoid or
     vitamin C would raise the strength if your goals call for it.
     [cites each product + ingredient .html page]

Concern → proven actives

You: I have melasma. What actives are proven, and which products have them?

Agent: [reads conditions/melasma] Top-evidenced actives for melasma, health
     claims only: … Then, products on SkinTiers that contain them: …
     Cosmetic "brightening" claims are kept separate. [cites the pages]

Claim check (stated vs. inferred)

You: Is CeraVe's "clinically proven" claim on product X actually supported?

Agent: [reads the product's grades notes] The health use is graded <effect> on
     <evidence> evidence versus <comparator>; the marketed phrase refers to a
     cosmetic appearance endpoint, not a health outcome — here's the gap. [cites]

Ingredient comparison

You: Tretinoin vs adapalene for a beginner?

Agent: [reads both ingredient pages] Effect and evidence for each, plus
     tolerability for a beginner, with the trade-offs the pages document. [cites both]

Educational, not medical advice. An agent using SkinTiers should say the same, and send you to a dermatologist for medical concerns.
